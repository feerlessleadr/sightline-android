## Sightline for Android 0.1.3

### What is new

- **Header.** The mark at the top of the app now matches the new lens icon, and the server name is light instead of black, so it can be read on the dark header.
- **Text colour.** Any text that is not inside a card or toolbar now defaults to the light colour too, so it can't turn black on the dark background.

### Known limits

- Everything from 0.1.2 still applies.

### Install

Download the APK below, or update from an app such as Obtainium pointed at this repository's releases. It is signed with the same key as earlier versions, so it installs over them and keeps your sign-in and settings. Check the download against the checksums at the bottom.
