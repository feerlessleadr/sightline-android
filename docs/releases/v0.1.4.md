## Sightline for Android 0.1.4

### What changed

- **Security fix: session token out of web addresses.** The "Test video start" tool in Settings > Developer had one test that put the Blue Iris session in the web address, where a reverse proxy or Blue Iris would write it to its logs. That test is removed. The session now travels only in a cookie, as everywhere else in the app.
- **Security fix: unsafe file names refused.** Camera names, recording files and export files that Blue Iris sends are now checked before the app builds an address from them. A name containing `.` or `..` parts is refused, so a wrong or hostile reply cannot steer a signed-in request to another path on the server. Normal names are unaffected.

### Known limits

- Everything from 0.1.3 still applies. Pictures of your cameras can still appear in the phone's app switcher; hiding them is being considered.

### Install

Download the APK below, or update from an app such as Obtainium pointed at this repository's releases. It is signed with the same key as earlier versions, so it installs over them and keeps your sign-in and settings. Check the download against the checksums at the bottom.
