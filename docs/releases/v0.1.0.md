## Sightline for Android 0.1.0

The first release: an Android viewer for your own Blue Iris server that follows the web app
[Sightline for Blue Iris](https://github.com/rw377/Sightline-for-Blue-Iris) as closely as Android allows. Unofficial, view-only,
and it talks only to your own server over HTTPS.

### What is in it

- **Sign in** to Blue Iris with a user name and password. Optionally remember the sign-in and unlock the app with your
  fingerprint or screen lock.
- **Live view:** the camera grid with groups, tile sizes, drag to reorder, live video or still pictures, coloured borders for
  motion and triggers, AI labels such as "Person 91%", and motion boxes.
- **Player:** one camera live, a scrubbable timeline with colour-coded alert marks, play and pause, jump between alerts, flag
  and protect an alert, and download an alert or any time range as an MP4 (to Downloads or a folder you choose).
- **Alerts tab:** a list with thumbnails, filters (People, Vehicles, Animals, Flagged, and your own labels, in Choose or Auto
  mode), a camera or group menu, time ranges, and tap to play.
- **Pop up on detection:** a camera pops up over the grid when something you chose is detected.
- **Server:** server status (CPU, memory, disks, frame rates, footage kept), the system log, and an activity overview.
- **Notification links:** `sightline://` links, so a Home Assistant notification can open a camera, an alert or the alerts list.
- Settings, a colour legend and About, with Copy diagnostics for problem reports.

### Needs

- Android 11 or newer.
- Blue Iris 6 (tested on 6.1.6.1). Older versions are not supported.
- An HTTPS address for your Blue Iris server. Plain `http://` is refused.

### Known limits

- Not in this version: PTZ controls, push notifications from Blue Iris itself (use Home Assistant links), and the web app's
  preview panel for wide screens. Tablet layouts are not finished.
- Several features were built and tested on one phone and one Blue Iris server. Expect rough edges and please report them.
- The system log needs a Blue Iris admin user; other users see a message saying so.
- Downloading a range that crosses two recording files has not been tested.

### Install

Download the APK below and open it on your phone (Android asks you to allow installing from that source). Check the download
against the checksums at the bottom. To get updates, use an app such as Obtainium pointed at this repository's releases; every
release is signed with the same key.

Report a problem: use Copy diagnostics in About, then open an issue on this repository. Please leave out passwords, server
addresses and camera names.
