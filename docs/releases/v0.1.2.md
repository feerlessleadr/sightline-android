## Sightline for Android 0.1.2

### What is new

- **New logo.** A lens: two cyan rings, a red live dot and a small highlight, on dark navy. It also has a single-colour version for Android's themed icons.
- **Updated libraries.** Jetpack Compose, the Android build tools, OkHttp, the serialisation library and GitHub Actions are all on their newest releases. The app now builds against Android 37.1. There are no changes to what the app does.

### Known limits

- Everything from 0.1.1 still applies, including no screen-reader alternative yet for dragging camera tiles and no "Smooth" preview mode.
- The library updates have had little testing on real devices. If anything behaves differently, please report it.

### Install

Download the APK below, or update from an app such as Obtainium pointed at this repository's releases. It is signed with the same key as earlier versions, so it installs over them and keeps your sign-in and settings. Check the download against the checksums at the bottom.
